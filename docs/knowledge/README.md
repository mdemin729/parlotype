# Knowledge notes

Facts that cannot be derived from the code: third-party quirks, environment gotchas, and
measured limits. Anything an ADR or the code already states does not belong here; link
to the ADR instead. Each note carries `title`, `area`, `summary` and `verified` in its
frontmatter.

This file is generated by `scripts/gen-docs-index.ps1` - do not edit it by hand.
`pwsh scripts/gen-docs-index.ps1 -Check` fails when it is stale.
