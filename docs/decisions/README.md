# Architecture Decision Records

An ADR records one decision: the context that forced it, what was decided, and what it
costs. The body of an accepted ADR is a historical record and is not rewritten; when a
decision changes, a later ADR says so. What is kept current is the frontmatter (`status`
and the `supersedes` / `superseded-by` / `amends` / `amended-by` links), and that is
what this table is built from. New ADRs start from [`_template.md`](_template.md).

`pwsh scripts/gen-docs-index.ps1 -Check` fails when it is stale.
