# ES glossary

No per-language glossary file was created for this culture during the original 25-language wave (ru/es were translated before that convention started). This file starts as a stub recording only later additions; the existing `Strings.es.resx` remains the source of truth for established terminology.

## Later additions

- `Settings_Prompts_BuiltInName` ("Default (verbatim transcription)", the built-in prompt's row label) → **"Predeterminado (transcripción literal)"** — verbatim/word-for-word rendered as *literal*, paired with the already-established *transcripción* for transcription; no new terms introduced.
