# Parlotype.Core

## Purpose
Pure domain layer containing all interfaces, models, enums, and records. Zero external NuGet dependencies. Every other project depends on Core.

## Key Paths
- `src/Parlotype.Core/Audio/` — `IAudioCaptureService`, `IMicrophoneEnumerator`, `IVoiceActivityDetector`, `IAudioLevelProvider`, `IAudioPipeline` (with default-no-op `PrewarmAsync`, ADR-038; `TranscriptionFailed` event + `TranscriptionErrorEventArgs` for surfacing per-utterance transcription failures without stopping the pipeline — ADR-043 amendment), `RecordingState` (`Disabled`/`Loading`/`Idle`/`Active`; `Loading` added by ADR-038)
- `src/Parlotype.Core/Speech/` — `ISpeechRecognizer`, `WhisperOptions`, `WhisperModelType`, `WhisperModelInfo` (with `SupportsTranslation` flag — false for `*En` models + `LargeV3Turbo`, see [[decisions/_index|ADR-033]]), `SpeechEngine` (Whisper/Gemma4/Parakeet local + `OpenAiCompatible`/`XaiGrok` cloud, **Parakeet is the default** — ADR-042; cloud values are opt-in BYOK per [[decisions/_index|ADR-032]]/[[decisions/_index|ADR-043]] — local by default, cloud by choice; both cloud engines are transcribe-only **and auto-detect-only** in `SpeechEngineCapabilities.For` (`SupportsSourceSelection: false` like Parakeet ⇒ `HasLanguageChoices` false ⇒ all language UI hides; source lists — Whisper set for OpenAI-compat, full catalog for xAI — document coverage only, ADR-043 amendment)), `Gemma4ModelInfo`, `ParakeetModelInfo` (2-entry catalog: `parakeet-tdt-0.6b-v3-int8` ~670 MB default + `parakeet-tdt-0.6b-v3-fp32` ~2.6 GB with optional `EncoderWeightsFileName` for the ONNX external-data file; per-model cache subdir, ADR-041 + amendment), `IPromptTemplateRegistry`, `PromptTemplate` (Gemma 4 prompt; `{speech_lang}`/`{text_lang}` tokens — retiring `{language}` — with `Substitute`/`Render` + `AutoDetectedLanguageName` "the detected language"; optional `TranslationText`/`AutoDetectText` bodies populated only on the built-in default, ADR-037), `LanguageInfo` + `LanguageCatalog` (curated `WhisperLanguages` ~99 + `ParakeetLanguages` 25 (subset of Whisper set, ADR-041) + `CultureInfo`-derived `AllLanguages` fallback; `AutoDetectCode`/`NoTranslationCode`/`KeyboardLayoutCode` sentinels + `IsKeyboardLayout`, ADR-036), `LanguageCapabilities` + `SpeechEngineCapabilities.For` (per-engine source set + `FixedTranslationTargets` — Whisper publishes `[English]`, ADR-035 — derived `TranslationForm` None/Toggle/Full, ADR-036, plus `SupportsSourceSelection` — false for Parakeet, whose source list only documents coverage — and derived `HasLanguageChoices` that hides all language UI when false, ADR-042), `TranslationForm` enum, `IKeyboardLayoutService` + `KeyboardLayoutInfo` (OS keyboard-layout language detection contract, ADR-036), `SourceLanguageResolver` (pure keyboard-sentinel → detected-language resolution with auto fallback, ADR-036), `RecentLanguages` (pure MRU helper, cap 5, role-agnostic — ignores all three sentinels), `LanguageSettingsMigrator` (idempotent one-shot migration from legacy `TranslateToEnglish` and shared `RecentLanguages` to `TranslationEnabled` + per-role MRUs, ADR-035) — all [[decisions/_index|ADR-034]] / [[decisions/_index|ADR-035]] / [[decisions/_index|ADR-036]], `RuntimePreference` (Auto/Vulkan/Cpu — CUDA removed, ADR-049), `RuntimeUnavailableException` (carries `RequiresRestart` — set when the process already latched another runtime, ADR-048), `IWhisperRuntimeStatus` (loaded-runtime view + `RequiresRestartFor`, ADR-048), `INvidiaEnvironmentProvider`, `NvidiaEnvironmentInfo`, `IVulkanEnvironmentProvider`, `VulkanEnvironmentInfo`, `VulkanDeviceInfo`
- `src/Parlotype.Core/Settings/` keys for language: `SelectedSourceLanguage`, `SelectedTargetLanguage`, `TranslationEnabled` (master toggle, ADR-035), per-role MRUs `RecentSourceLanguages` / `RecentTargetLanguages` (ADR-035). Legacy `TranslateToEnglish` and shared `RecentLanguages` keys retained for one-shot migration only
- `src/Parlotype.Core/Hotkeys/` (multi-gesture model, [[decisions/_index|ADR-047]]) — `IGlobalHotkeyService` (semantic `DictationStartRequested`/`DictationStopRequested`/`DictationCancelRequested`/`BindingsChanged` events, `Bindings`/`UpdateBindings`, `SetDictationActive`), `DictationHotkey` (gesture + `ActivationMode`, with the kind→mode validity matrix), `HotkeyGesture` (`Chord`/`HoldModifier`/`DoubleTapModifier`) + `HotkeyGestureKind`, `ModifierKey`/`ModifierSide`, `DictationHotkeyDefaults` (Hold Right Ctrl PTT + Double-tap Ctrl toggle + Ctrl+Alt+Space toggle), `HotkeyGestureMatcher` + `DictationAction`/`HotkeyMatchResult` (raw events → intent + suppression flag; `NextTimeoutMs`/`ProcessTimeout` drive the deferred hold-start), `HotkeyKeyEvent` (hook-agnostic normalized key event), internal `ModifierTapTracker`/`ModifierHoldTracker` state machines + `HotkeyGestureTiming` (tap 250 ms, double-tap window 350 ms, hold-abort grace 300 ms), `HotkeyBinding` (chord payload), `HotkeyConflictDetector.Check` + `HotkeyConflict`/`HotkeyConflictSeverity` (Blocking vs Warning), `HotkeyBindingCodec` (readable string form for settings), `HotkeySettingsMigrator` (one-shot legacy-triple migration), `HotkeyHint` (record-button tooltip text)
- `src/Parlotype.Core/Settings/` — `ISettingsService`, `SettingsKeys` (long-lived, user-configured settings; cloud-provider keys `OpenAiCompatBaseUrl`/`OpenAiCompatModel`/`XaiGrokBaseUrl`/`XaiGrokModel` plus secret-store lookup names `OpenAiCompatApiKey`/`XaiGrokApiKey` — ADR-043), `ISecretStore` (small-secret storage contract — API keys; values live outside `settings.json`, encrypted at rest where the OS supports it; null/empty `SetAsync` removes — ADR-043). Deliberately separate: `IWindowStateService`, `WindowStateKeys`, `WindowPosition` (transient window-chrome state — position — that saves far more often, e.g. every drag; never shares a file/lock with `ISettingsService`, ADR-040)
- `src/Parlotype.Core/TextInjection/` — `ITextInjectionService`, `ITargetWindowTracker`
- `src/Parlotype.Core/Settings/` app paths (ADR-053) — `IAppPaths` + `AppPaths` (`.Default`), the single source of truth for every path the app writes to: `DataDirectory`, `SettingsDirectory`, `ModelsDirectory`, `LogsDirectory`, `LlamaServerDirectory`, `LlamaServerInstallsDirectory`, `SettingsFilePath`, `SecretsFilePath`, `WindowStateFilePath`. Windows root is `%LOCALAPPDATA%/parlotype-data` — **not** `parlotype`, which is the Velopack pack folder and is deleted on uninstall/reinstall; macOS uses `~/Library/Application Support/Parlotype` + `~/Library/Logs/Parlotype`, Linux follows XDG. The concrete `AppPaths` is exceptionally in Core (not Platform) because `ParakeetModelInfo`/`Gemma4ModelInfo` must resolve the model cache and Core cannot reference Platform — it depends on nothing but the BCL. Resolving a path never creates directories
- `src/Parlotype.Core/Updates/` (ADR-053) — `IUpdateService` (`Status`, `StatusChanged`, `CurrentVersion`, `StartAsync`, `CheckAsync(userInitiated)`, `ApplyOnExit()`, `ApplyAndRestartAsync`), `UpdateStatus` record, `UpdateState` enum (`Idle`/`NotInstalled`/`Checking`/`UpToDate`/`UpdateAvailable`/`Downloading`/`ReadyToApply`/`Failed`). `ApplyOnExit` is deliberately **sync** — shutdown handlers are not a reliable place to resume a continuation. Contract spells out that downloading only *stages* a release and nothing installs without an explicit apply. Contract requires the check to send nothing beyond what fetching the public feed needs — no machine id, install id, usage data, or custom headers
- Security/perf additions (ADR-045/046): `AudioDataEventArgs.Buffer` is contractually valid **only during the `DataAvailable` event** (may be pool-backed — handlers copy synchronously); `ModelIntegrityException` (SHA-256 mismatch on model download, carries FileName/Expected/Actual); `CloudBaseUrlValidator` (HTTPS-or-loopback rule for cloud base URLs); model catalogs carry SHA-256 digests — `WhisperModelInfo.Sha256` (replaced the never-consumed SHA-1 `Sha`), `ParakeetModelInfo.FileSha256` map + `GetSha256(fileName)`, `Gemma4ModelInfo.GgufSha256`/`MmprojSha256` + `GetSha256(fileName)`

## Conventions
- Interfaces only — no implementations
- No platform-specific packages ever
- Subfolder structure mirrors Platform's implementation layout
- New domain contracts go here first, then implement in [[platform]]

## Dependencies
None (by design).
